# Mission 00 — Repository Setup

## 1. Task / Objective

The objective of this mission was to create a properly organised GitHub repository for the Digital Detective assignment and prepare the folder structure required for all missions.

## 2. Work Completed

- Created the project folder named `digital-detective-8481`.
- Created separate folders for all nine missions.
- Created individual README.md files for each mission.
- Created the Python files required for upcoming programming activities.
- Created the root README.md containing the project introduction and mission index.
- Opened the project in Antigravity IDE.
- Initialised Git and connected the local repository to GitHub.
- Created the first Git commit and pushed the project to GitHub.

## 4. My Understanding

I learned that a GitHub repository provides an organised place to store and manage project files. Creating separate folders for each mission makes the project easier to navigate and maintain.

I also understood the basic Git workflow: initialise a repository, stage files, commit changes and push them to GitHub.

## 5. Difficulties Faced

Initially, the local project folder was not initialised as a Git repository. The GitHub remote repository was also not connected.

## 6. How I Resolved Them

I used `git init` to initialise the local repository and `git remote add origin` to connect it to my GitHub repository. I then staged, committed and pushed the project files successfully.

## 3. IPOS Model

The IPOS model describes the four basic stages of computer operation.

- **Input:** Data or instructions entered into a computer.
- **Processing:** The CPU or other processing components execute instructions and process data.
- **Output:** The processed information is presented to the user.
- **Storage:** Data and information are saved for future use.

### Example: Calculator

When I calculate 50 × 2:

- Input: I enter 50 × 2 using the keyboard or calculator interface.
- Processing: The processor performs the calculation.
- Output: The screen displays 100.
- Storage: The result may be saved in calculator history, depending on the application.

## 4. Hardware and Software

**Hardware:** Physical components of a computer, such as the keyboard, CPU, monitor and SSD.

**Software:** Programs and instructions that tell computer hardware what tasks to perform, such as macOS and Google Chrome.

## 5. Three Everyday Computer Systems

### System 1: Smartphone

- Input: Touchscreen and microphone.
- Processing: The processor executes instructions and processes data.
- Output: Display screen and speakers.
- Storage: Internal storage keeps photos, applications and files.

### System 2: Smartwatch / Fitness Band

- Input: Sensors collect measurements such as heart rate and movement.
- Processing: The processor analyses the collected sensor data.
- Output: The display shows activity information and measurements.
- Storage: Activity records and settings may be stored in device memory.

### System 3: Washing Machine

- Input: User-selected washing settings.
- Processing: The controller manages the washing cycle.
- Output: Washing operation and status display.
- Storage: Some models store saved settings or washing programs.

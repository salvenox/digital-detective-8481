## 4. Flags and Pipes

Flags are additional options that change how a command works.

Example:

`ls -la`

- `-l` displays detailed file information.
- `-a` includes hidden files.

A pipe (`|`) passes the output of one command as input to another command.

Examples:

- `ls | sort` — Sorts the listed files and directories.
- `ls | grep mission` — Displays entries containing the word mission.
- `ls | wc -l` — Counts the lines in the listing.

## 5. Compiler vs Interpreter

| Compiler | Interpreter |
|---|---|
| Translates source code into another form before execution. | Executes a program through an interpreter at runtime. |
| Compiled programs commonly produce executable or intermediate output. | Execution is managed by the interpreter. |
| C and C++ are common examples of compiled languages. | Python is commonly described as an interpreted language. |

Python implementation detail: CPython first compiles Python source code into bytecode and then executes it using the Python Virtual Machine.
